Política de Privacidade

shorts-factory — atualizada em 16 de setembro de 2026

Resumo

O shorts-factory é um programa que roda no computador do próprio usuário. Não existe servidor, banco de dados ou cadastro. Nenhuma informação é enviada para nós, porque não há um "nós" recebendo nada: o programa conversa apenas com o computador local e com as APIs oficiais dos serviços que o próprio usuário conectar.

Dados acessados no TikTok

Quando o usuário conecta a própria conta, a ferramenta solicita dois escopos:

  • user.info.basic — lê o nome de exibição da conta, apenas para mostrar na tela qual conta está conectada.
  • video.upload — envia arquivos de vídeo para a caixa de rascunhos da conta.

A ferramenta não lê vídeos existentes, não acessa mensagens, não consulta seguidores e não publica nada automaticamente. Os vídeos enviados ficam nos rascunhos até que o usuário decida publicá-los manualmente dentro do aplicativo do TikTok.

Onde os dados ficam

  • Os tokens de acesso são gravados em um arquivo local, na pasta do programa, no computador do usuário.
  • Os vídeos gerados ficam em uma pasta local.
  • Nada é transmitido para servidores de terceiros além das próprias APIs oficiais usadas para transcrição e publicação, sempre com credenciais do próprio usuário.

Senhas

A ferramenta nunca vê nem armazena senhas. A autenticação acontece no site da própria plataforma, pelo fluxo OAuth padrão. O programa recebe apenas um token de acesso.

Compartilhamento

Nenhum dado é vendido, cedido ou compartilhado com terceiros. Não há publicidade, não há rastreamento e não há analytics.

Como revogar o acesso

O usuário pode desconectar a ferramenta a qualquer momento nas configurações do TikTok, em Configurações e privacidade → Segurança e permissões → Gerenciar permissões de aplicativos. Também pode apagar o arquivo local de tokens, o que invalida o uso pelo programa imediatamente.

Retenção

Como todos os dados ficam no computador do usuário, a exclusão é feita por ele, apagando os arquivos. Não há cópia em nenhum outro lugar.

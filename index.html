shorts-factory

Ferramenta pessoal que transforma vídeos longos do YouTube em cortes verticais legendados.

O que faz

É um programa de linha de comando que roda no computador do próprio usuário. A partir do link de um vídeo do YouTube, ele:

  1. baixa o vídeo e extrai o áudio;
  2. transcreve a fala com marcação de tempo por palavra;
  3. escolhe os trechos que funcionam como vídeo curto;
  4. recorta em formato vertical (1080x1920) e queima a legenda;
  5. gera título, descrição e hashtags para cada corte.

Integração com o TikTok

O usuário pode, opcionalmente, conectar a própria conta do TikTok para enviar os vídeos gerados. Os vídeos são enviados para a caixa de rascunhos da conta: nada é publicado automaticamente. A publicação é sempre uma ação manual do usuário dentro do aplicativo do TikTok.

A ferramenta usa apenas dois escopos: user.info.basic, para exibir o nome da conta conectada, e video.upload, para enviar o arquivo aos rascunhos.

Quem usa

É uma ferramenta de uso pessoal, operada pelo próprio dono da conta, no computador dele. Não há serviço hospedado, não há cadastro e não há acesso a contas de terceiros.
